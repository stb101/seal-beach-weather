SEAL BEACH WEATHER STATION — PWA PACKAGE

Files:
- index.html — dashboard
- manifest.webmanifest — makes it installable
- sw.js — PWA service worker
- icon-192.png / icon-512.png — home-screen icons

Hosting:
Upload all five files together to the root of an HTTPS static website (for example GitHub Pages or Cloudflare Pages).

After hosting:
1. Open the HTTPS site in Chrome on the Galaxy Tab S6 Lite.
2. Chrome menu (⋮) > Add to Home screen / Install app.
3. Open “SB Weather” from its new icon.
4. It will launch in landscape standalone mode without normal Chrome tabs/address bar.

The dashboard still needs Internet access for live weather, radar, map tiles and alternate map layers.
